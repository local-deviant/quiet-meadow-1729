One original dad joke, at most 200 characters, written to be told out loud at the dinner table: a father asks the kitchen blender how it is feeling, and the blender answers in a single word. Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
